# EDNA — Evidence-Grounded Knowledge Platform

Private, lightweight evidence repository for a validated portfolio prototype.

## Reproduce

```bash
make setup
make test
make reproduce
make docs
```

The prototype uses a deliberately small local corpus derived from system charter and five canonical project records; no closed-course content is copied. Its results are technical evidence, not a claim of production deployment or client impact. Start with `docs/DOSSIER.md` and verify `artifacts/evidence-manifest.json`.
